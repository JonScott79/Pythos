Pythos 1.8.0

Latest Release
September 16, 2026
✦ WHAT'S NEW
  • Per-User Learning Store Isolation (P0): Verified learning corrections are now strictly partitioned by authenticated student UID under users/{uid}/pythos_learning/{recordId}, eliminating cross-user learning data leakage across sessions and container restarts.
  • Deterministic Student Intent Classification (P1): New multi-signal deterministic classifier identifying 11 distinct student conversational intents (proposed answers, proposed steps, validation requests, corrections, reframe requests, confusion, etc.) prior to LLM reasoning.
  • Student-Proposed Math Evaluation & Check-My-Work (P1): Deterministically evaluates student-proposed mathematical steps and exact rational $\pi$ arithmetic (e.g. -29/3 pi + 2pi * 5 evaluates to $\pi/3$) before model generation. Ambiguous notations (such as 1/2x or sin 30) are safely tagged as ambiguous without guessing.
  • Mandatory Revision Re-Verification (P1): When initial LLM generations contain invalid claims, the resulting revision is now fully re-verified deterministically before sending to ensure secondary errors are caught.
  • Generalized Algebraic Claim Extraction (P2): Generalized linear and quadratic equation extraction with direct root substitution verification in Math.js.
⚖️ SECURITY & INTEGRITY GUARDRAILS
  • Explicit Firestore Security Rules (P0): Added explicit Firestore security rules for pythos_memory and pythos_learning, permitting authenticated users to read only their own data while strictly denying all client-side writes.
  • Memory Poisoning Defense (P1): Memory extraction rejects attributed speech (“my friend says my name is...”), quoted speech, hypotheticals, negated names, and false mathematical propositions (“remember that 2 + 2 = 5”) from entering persistent memory.
  • Identity Authority Hierarchy: Maintains strict authority separation: Authenticated Account Identity > Verified Math Facts > Student Explicit Statements > Conversation Context > LLM Inference.
  • Comprehensive Regression Verification: 18 test suites and 197/197 tests passing (100% green).
