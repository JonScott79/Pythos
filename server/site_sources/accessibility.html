Accessibility Statement

Standard: WCAG 2.2 Level AA • Automated & Manual Audit Score: 100/100 (Desktop & Mobile)

1. Commitment to Accessible STEM Education

Pythos is built on the principle that every student deserves free, rigorous mathematics and physics instruction regardless of disability or assistive technology. We engineer our workspace to conform to the Web Content Accessibility Guidelines (WCAG) 2.2 Level AA.

2. Screen Reader & Mathematical Notation Support

  • Semantic MathML + TeX Annotations: Every equation rendered via KaTeX includes embedded MathML (`katex-mathml`) and semantic speech-order extraction so fractions (`numerator/denominator`), roots, integrals, and boxed final answers (`role="math"`) are read accurately by NVDA, JAWS, and VoiceOver.
  • Live Regions Without Chatter: The conversation log (`#output`) uses `role="log"` and `aria-live="polite"`, while rotating thinking animations use `aria-hidden="true"` with a single polite status announcement to prevent screen-reader chatter.
  • WCAG 2.5.3 Label-in-Name Compliance: All interactive buttons and links with `aria-label` attributes preserve their visible text label for speech-input users (Dragon NaturallySpeaking, Voice Control).

3. Keyboard Navigation & Focus Management

  • Skip Links: Press `Tab` on page load to jump directly to the math input (`#userInput`) or conversation log (`#output`).
  • Keyboard-Accessible Message Actions: Message action toolbars (Read Aloud, Copy, Report, Feedback) automatically appear when any button inside a message receives keyboard focus (`:focus-within`).
  • Modal Focus Containment & Escape Dismissal: All floating calculators, graphers, simulation labs, and dialogs support `Escape` key dismissal and restore focus to the invoking trigger button.

4. Visual Contrast, Motion & Touch Targets

  • High-Contrast Light & Dark Modes: Text and interactive controls exceed WCAG AA contrast ratios (`4.5:1` normal text, `8.54:1` on primary dark-mode CTAs).
  • Reduced Motion: Respects `@media (prefers-reduced-motion: reduce)` across all transitions and animations.
  • Touch Targets: Interactive controls and mobile range sliders meet or exceed the WCAG 2.5.8 minimum target size (`24x24` CSS pixels).
